# Сільпо × Bolt Food — пропозиція запуску кулінарії

Партнерський one-pager: 12-місячний plan для 100 локацій, умови delivery на кур'єрах Bolt, умовне зниження комісії Dark Kitchen та launch marketing.

## PDF

Відкрийте `index.html` у браузері та натисніть **«Завантажити PDF»**. Документ має print-стилі для A4 landscape.

## Умови пропозиції

- Stores на кур'єрах Bolt — 12%.
- Dark Kitchen — 25% у М1–3; 20% у М4–12 лише після досягнення 2,540 delivered orders та €33k товарного GMV у stores за перші 3 місяці.
- Якщо поріг не досягнуто, DK повертається / залишається на 25%.
- Bolt Plus і free delivery для Plus — 6 місяців.
